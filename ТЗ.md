# Технічне Завдання (ТЗ): Цифровий Інструмент для Аналізу Кандидатів у Секторі Безпеки та Оборони

---

## МЕТА

Розробити **цифровий інструмент** (веб- або мобільний застосунок), який дозволяє **автоматизовано аналізувати** професійний досвід, репутацію та доброчесність кандидата на посаду у секторі безпеки та оборони.

> **Мета** – створити систему, що допомагає кадровим комісіям, HR-підрозділам і антикорупційним уповноваженим оцінювати кандидата **не лише за формальними документами**, а й за **комплексом етичних, управлінських та поведінкових показників**.

---

## ЗАВДАННЯ КОМАНДИ

Команда має створити **прототип рішення**, яке дозволяє:

1. **Збирати та структурувати дані** про кандидата з різних джерел  
   *(резюме, анкета, відкриті бази, внутрішні звіти)*

2. **Оцінювати релевантність досвіду** під конкретну посаду  
   *(компетенції, послужний список, рівень відповідальності)*

3. **Виявляти потенційні ризики**  
   *(конфлікт інтересів, часта зміна посад, порушення дисципліни, невідповідність критеріям)*

4. **Формувати профіль кандидата** з інтегрованим показником  
   `рівень довіри / доброчесність / управлінська зрілість`

5. **Генерувати коротке резюме-аналітику** для прийняття кадрового рішення

---

## ОЧІКУВАНИЙ РЕЗУЛЬТАТ

**Робочий прототип застосунку**, який:

1. Дозволяє оцінювати досвід та доброчесність **у стандартизований спосіб**
2. Має **зручну систему введення, фільтрації й візуалізації даних**
3. **Автоматично формує профіль або рейтинг кандидата**
4. Може бути використаний у:
   - кадрових процесах
   - конкурсних відборах
   - внутрішніх перевірках

## ОРІЄНТОВНИЙ ФУНКЦІОНАЛ

- **Інтерфейс введення даних**  
  *(анкета, завантаження документів, посилання на профілі)*

- **Алгоритм оцінки досвіду**  
  *співставлення: досвід ↔ компетенції ↔ вимоги посади*

- **Система виявлення ризиків**  
  *конфлікт інтересів, часті переходи, неповна освіта, дисциплінарні порушення*

- **Профіль довіри**  
  *графічна візуалізація: професійність / доброчесність / відповідальність / надійність*

- **Експорт звіту**  
  *PDF або дашборд для керівника*

- *(опційно)* **Порівняння кандидатів**
- *(опційно)* **Оцінка потенціалу** – тести/опитування

## РЕКОМЕНДАЦІЇ ДО КІНЦЕВОГО РІШЕННЯ

### ФУНКЦІОНАЛЬНІ РЕКОМЕНДАЦІЇ

1. **Модуль імпорту даних** – резюме, анкета, JSON, CSV
2. **Автоматична перевірка непослідовностей**  
   *(дати, кваліфікації, прогалини в досвіді)*
3. **Інтерактивний дашборд**  
   *графіки, індикатори ризику, профіль довіри*
4. **Вагові коефіцієнти**  
   *користувач налаштовує важливість критеріїв*

   `введення → аналіз → результат`
2. **Інтерактивна шкала довіри** або *heatmap*
3. **Інтуїтивна навігація** – для не-технічних користувачів
4. **Попередження про персональні дані** (GDPR-подібне)

---

## ВИМОГИ ДО ПРЕЗЕНТАЦІЇ РЕЗУЛЬТАТУ

Під час **фінального захисту** команда представляє:

1. **Демо роботи** (2–3 хв) – приклад одного кандидата
2. **Візуалізація оцінки** – як обчислюється профіль довіри
3. **Архітектура рішення**  
   *(структура даних, логіка, прозорість)*
4. **Масштабування** – інтеграція з системами МОУ
